Why nette

Readability as a check,
not an opinion.

Linters check syntax. Tests check behavior. Nothing checks whether the code your agent just wrote can be read by the next human. nette closes that gap.

Diff-aware by default

Only the lines you just wrote count. A 10-year-old repo is never all red.

Calibrated on your repo

Five exemplary codebases diverge 12x on style while all being exemplary. So nette learns your baseline and flags deviation from it, never from an absolute.

Deterministic. No LLM.

Same code, same verdict, < 100ms warm. Fast enough for the agent's write-check-fix loop, cacheable byte-for-byte.

Rules

Names that say what they detect.

No lookup tables, no numeric codes. An agent reading a finding knows what to do without a round-trip to the docs.

function-length
a function is too long to take in at one glance
nesting-depth
code nests too deeply to follow
argument-count
a function takes too many required arguments
short-name-long-scope
a one-letter name lives too long
naming-drift
an identifier breaks the repo's own convention
over-guarded
a file guards far more than the rest of the repo
guard-density
one function stacks guards line after line
under-annotated
a file drops the type annotations the repo keeps
file-size
a file dwarfs the repo's norm

Baselines freeze your debt one violation at a time. rubocop --auto-gen-config raises the limit to match your worst file, so a repo that drifted locks the drift into its config. A nette profile can tighten, and relaxing it takes an explicit --reset that shows up in the diff of a committed file. Surveyed August 2026 against each tool's own documentation.

How it works

Three commands.

Calibrate once

$ nette calibrate

nette measures your repo's style (guard density, file sizes, naming) and writes a committed profile. CI, humans, and agents share the same baseline.

Check the diff

$ nette check --diff

Only what changed is judged. Every finding names the problem, the reason, and the fix direction.

Wire the agent

$ nette check --diff --format agent

Deterministic JSON with a ready-to-act instruction per finding. Identical input, identical bytes: agent runs cache and diff cleanly.
