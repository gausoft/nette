Why nette

Readability as a check,
not an opinion.

Linters check syntax. Tests check behavior. Nothing checks whether the code your agent just wrote can be read by the next human. nette closes that gap.

Diff-aware by default

Only the lines you just wrote count. A 10-year-old repo is never all red.

Calibrated on your repo

Five exemplary codebases diverge 12x on style while all being exemplary. nette learns your baseline and flags deviation from it, never from an absolute.

Deterministic. No LLM.

Same code, same verdict, < 100ms warm. Fast enough for the agent loop, cacheable byte-for-byte.

Rules

Names that say what they detect.

No lookup tables, no numeric codes. An agent reading a finding knows what to do without a round-trip to the docs. Six of the fifteen:

function-length
a function is too long to take in at one glance
nesting-depth
code nests too deeply to follow
naming-drift
an identifier breaks the repo's own convention
over-guarded
a file guards far more than the rest of the repo
duplicated-sibling
a function is a near-copy of a sibling function
mixed-module
data types pile up in a module that also holds logic
All fifteen rules, with thresholds

Baselines freeze your debt one violation at a time. rubocop --auto-gen-config raises the limit to match your worst file, so a repo that drifted locks the drift into its config. A nette profile can tighten, and relaxing it takes an explicit --reset that shows up in the diff of a committed file. Clippy, SwiftLint, Checkstyle, clang-tidy and Credo sit in the same column as ESLint here; the full survey, run August 2026 against each tool's own documentation, is in the benchmark doc.

How it works

Three commands.

Install with pip install nette. Zero dependencies, Python 3.11+.

Calibrate once

$ nette calibrate

nette measures your repo's style (guard density, file sizes, naming) and writes a committed profile. CI, humans and agents share one baseline.

Check the diff

$ nette check --diff

Only the lines you touched are judged. Every finding names the problem, the reason and the fix direction.

Wire the agent

$ nette check --diff --format agent

Deterministic JSON with a ready-to-act instruction per finding. Identical input, identical bytes.
